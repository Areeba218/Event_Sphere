# FAQ
**I did not get the verification email.** Check spam. Administrators can set `EMAIL_MODE=console` in development to read links in the server terminal.
**I forgot my password.** Use *Forgot password*; the link expires after a short time.
**Why can't I reserve a booth?** Only approved exhibitors can reserve; one booth per event; the booth must still be available.
**How do reminders work?** About 30 minutes (configurable `REMINDER_MINUTES`) before a session you registered for or bookmarked: in-app notification, plus email if enabled.
**Can others see my email?** Only if *Share my email and phone* is on in your profile.
**How do I delete my data?** Profile → Privacy & data (download or delete). Organizers must delete their events first.
**What file types can I upload?** PNG, JPG, WEBP, GIF and PDF up to 5 MB. Contents are verified.
**Supported browsers?** Current Chrome, Firefox, Safari, Edge; desktop and mobile.
**Where do I report a problem?** Dashboard → Feedback → *Report an issue*.

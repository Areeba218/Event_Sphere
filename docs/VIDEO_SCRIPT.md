# Demo video script (≈10 minutes)

**Prep:** `cd backend && npm run seed`, start backend and frontend, open two browser windows (organizer + attendee) side by side. Screen-record with any tool (OBS, Xbox Game Bar `Win+G`). Password for demo users: `Demo1234`.

| Time | Show | Say |
|---|---|---|
| 0:00 | Home page | What EventSphere is; the three roles |
| 0:40 | Register (consent box, password rules), verification mail, login, forgot password | Secure accounts |
| 1:40 | **Organizer**: create an event (theme, capacity), edit it | Expo management |
| 2:40 | Exhibitors tab: approve NovaTech, reject with note | Application workflow |
| 3:20 | Floor plan: generate booths, assign GreenLeaf | Booth allocation |
| 4:00 | **Exhibitor** (exhibitor1): edit profile + upload logo, reserve a booth; organizer window shows live notification and confirms | Reservation + real time |
| 5:00 | Booth panel: products, staff, neighbours → message neighbour | Collaboration |
| 5:40 | Organizer: add session, room clash blocked, edit time | Schedule management |
| 6:20 | **Attendee**: register for event, search exhibitors by category, view on floor plan, message exhibitor | Discovery |
| 7:10 | Bookmark + register session; organizer edits it → attendee notification appears live; reminder | Notifications |
| 8:00 | Organizer analytics updating live; Export CSV | Analytics |
| 8:40 | Feedback with rating; organizer resolves it | Support |
| 9:10 | Profile → privacy settings, download data; `/privacy`, `/help` | GDPR |
| 9:40 | Terminal: `npm test` (39 passing), `/health`, `npm run backup` | Quality & operations |
